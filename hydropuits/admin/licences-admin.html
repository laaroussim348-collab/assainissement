📋 Comment ça marche
1
Le client installe HydroPuits et le lance → un essai gratuit démarre automatiquement, sans rien à saisir. Son poste apparaît ici tout seul (colonne Identifiant Machine), avec le statut Essai et le temps restant.
2
Passé le délai d'essai, le poste passe automatiquement En attente de paiement dans ce tableau (surligné) — le client voit son Identifiant Machine à l'écran et est invité à vous contacter.
3
Une fois le paiement reçu, cliquez ✅ Activer en face de la ligne correspondante (vous pouvez retrouver le poste par l'Identifiant Machine que le client vous a communiqué, ou par la date de première connexion).
4
C'est tout — aucun code à transmettre. L'application du client se débloque automatiquement au prochain contrôle (toutes les 60s si elle est ouverte).
5
Pour bloquer un poste : cliquez ⛔ Révoquer. Effet au prochain contrôle (jusqu'à 7 jours de grâce si le poste était hors-ligne au moment de la révocation).
⚙️ Configuration Google Sheets — Instructions complètes
Prérequis : un compte Google (Gmail). Tout est gratuit. Le script Google Apps Script sert de serveur d'activation pour HydroPuits (routes appelées par src/services/activationClient.js). Ce script crée lui-même l'onglet Installations dans votre classeur au premier appel — aucune colonne à créer à la main.
Étape 1 — Créer le Google Sheet
  1. Ouvrez sheets.google.com → Nouveau classeur
  2. Nommez-le HydroPuits_Licences (le nom exact n'a pas d'importance — le script gère ses propres onglets)
Étape 2 — Créer le Google Apps Script
  1. Dans votre Sheet → menu Extensions → Apps Script
  2. Effacez tout le contenu existant et collez ce code :

Le bouton Copier colle automatiquement la clé d'administration actuellement saisie ci-dessus à la place de __ADMIN_KEY__.

  1. Cliquez Déployer → Nouveau déploiement
  2. Type : Application Web
  3. Exécuter en tant que : Moi
  4. Qui a accès : Tout le monde (nécessaire pour que HydroPuits puisse s'enregistrer)
  5. Cliquez Déployer → autorisez les permissions demandées
  6. Copiez l'URL affichée (commence par https://script.google.com/macros/s/) et collez-la dans le champ URL Google Apps Script en haut de cette page
Étape 4 — Configurer chaque copie de HydroPuits distribuée
  1. Dans le projet HydroPuits, ouvrez le fichier license-config.json (à la racine) et vérifiez que licenseServerUrl contient bien la même URL que ci-dessus
  2. Ce fichier fait partie des sources livrées à chaque client (embarqué dans l'archive .asar Electron) — la même URL est utilisée pour tous les postes, seul l'Identifiant Machine change
✓ Une fois configuré : chaque démarrage de HydroPuits (et chaque contrôle périodique, toutes les 60s) s'enregistre/se vérifie auprès de votre Google Sheet. Si vous modifiez le code du script après un premier déploiement, utilisez Déployer → Gérer les déploiements → ✏️ → Nouvelle version pour que les changements prennent effet (l'URL reste la même). En cas de coupure réseau, un poste déjà activé garde l'accès jusqu'à 7 jours depuis sa dernière vérification réussie, puis se bloque automatiquement si le serveur reste injoignable. Un poste en essai continue de décompter localement en cas de coupure réseau (redevient autoritaire dès que le serveur répond).
⚠️ Changement de modèle : ce script remplace l'ancien système à codes d'activation (action=verify/add sur la feuille de calcul "code/machineId/client/days/status"). Si vous avez déjà distribué des codes à des clients avec l'ancienne version, ce nouveau script ne les reconnaît plus — contactez ces clients pour les faire passer sur ce nouveau modèle (ils réapparaîtront automatiquement ici dès leur prochain lancement, en essai ou à activer directement).
